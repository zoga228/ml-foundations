# ML Foundations

Earlier learning exercises collected in one place so the portfolio foregrounds deeper experiments.

| Exercise | Method | Original repository |
|---|---|---|
| [House prices](exercises/PRODIGY_ML_01) | Linear regression | [Original history](https://github.com/zoga228/PRODIGY_ML_01) |
| [Customer segments](exercises/PRODIGY_ML_02) | K-means | [Original history](https://github.com/zoga228/PRODIGY_ML_02) |
| [Cats vs dogs](exercises/PRODIGY_ML_03) | Image features and SVM | [Original history](https://github.com/zoga228/PRODIGY_ML_03) |
| [Hand gestures](exercises/PRODIGY_ML_04) | Compact CNN | [Original history](https://github.com/zoga228/PRODIGY_ML_04) |
| [Food recognition](exercises/PRODIGY_ML_05) | CNN / MobileNet | [Original history](https://github.com/zoga228/PRODIGY_ML_05) |

Each folder retains its original README and requirements. Dataset downloads may require accepting the relevant Kaggle rules. `--demo` runs are synthetic smoke tests, not benchmark results. No new accuracy claim is made by this collection. Food-calorie values are approximate lookup estimates per serving; a classifier does not infer portion mass from a single image.

For recent measured work, see [Causal LM Lab](https://github.com/zoga228/causal-lm-lab) and [Validation Stress Lab](https://github.com/zoga228/validation-stress-lab).
